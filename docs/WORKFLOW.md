# Thesis workflow

Use GitHub as the version-control record and Overleaf as the collaborative LaTeX workspace.

## Source of truth by artifact

- LaTeX manuscript: `tesis/manuscript/`
- References: `tesis/references/`
- Figures: `tesis/figures/`
- CAD: `tesis/cad/`
- ANSYS: `tesis/ansys/`
- Experimental records: `tesis/experiments/`
- Analysis scripts/results: `tesis/analysis/`
- Overleaf integration notes: `tesis/overleaf/`

## Experimental traceability

Every dataset should carry an experiment identifier and metadata for configuration, temperature, vibration frequency, acceleration, displacement, capacitive output and acquisition state.

## Validation traceability

Keep baseline and protected configurations comparable under equivalent boundary conditions. Preserve raw measurements and generated/processed results separately.
