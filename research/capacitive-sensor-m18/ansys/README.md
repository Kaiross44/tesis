# ANSYS / FEM

Primera campaña: modelo electrostático 3D de H1 con barrido del entrehierro `g` y de la distancia al objetivo `d_target`.

Resultados esperados:
- capacitancia equivalente;
- magnitud y distribución del campo eléctrico;
- sensibilidad respecto de la geometría;
- datos exportables para comparación con Python.

Toda dimensión interna hipotética deberá quedar documentada como tal y asociada a una fuente o justificación.
